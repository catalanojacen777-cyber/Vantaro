# Reference parity checklist

Reference: https://founderpal.ai (functional reference only; no copy, code, claims or assets reused).
Checked: 2026-10-15 (research for the build brief) and 2026-10-16 (sitemap re-check during the build).

## How this was verified

- **S** = listed in the reference's public sitemap index (`/sitemap.xml`, 83 child sitemaps), fetched 2026-10-16.
- **R** = observed in the 2026-10-15 research recorded in the build brief (homepage, free-tools page, pricing, strategy page and four tool pages).
- **Unverified** = the reference renders page bodies in the browser; the fetch tool used here returns only metadata, so field-level details could not be re-read. Nothing was copied, and nothing behind sign-in or payment was accessed.
- Vantaro behavior marked **proposed enhancement** goes beyond what was observed.

Status values: **Implemented and tested**, **Implemented, awaiting external setup**, **Not implemented**, **Deliberately not replicated** (with the reason).
